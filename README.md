# Portfolio Demo

เว็บไซต์ Portfolio ตัวอย่างภาษาไทย ทำด้วย HTML และ CSS แบบ static ไม่ต้องติดตั้ง dependencies

## เผยแพร่ด้วย GitHub Pages

Repository นี้มี GitHub Actions workflow สำหรับเผยแพร่เว็บไซต์จาก branch `main` เมื่อ push โค้ดแล้ว ให้ไปที่ **Settings → Pages** ของ repository และเลือก **GitHub Actions** ในส่วน Build and deployment หากยังไม่ได้เลือก จากนั้น workflow จะ deploy เว็บไซต์ให้โดยอัตโนมัติเมื่อมีการ push ครั้งถัดไป
